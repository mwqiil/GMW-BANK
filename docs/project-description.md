# Описание проекта G.M.W Bank

## Тема

**G.M.W Bank: разработка цифровой банковской платформы с личным кабинетом, виртуальными картами, переводами и аналитикой расходов.**

## Цель проекта

Разработать учебную fullstack-модель цифрового банка, позволяющую пользователям управлять виртуальными счетами, картами и переводами через современный веб-интерфейс.

## Задачи

1. Спроектировать клиент-серверную архитектуру приложения.
2. Создать frontend с адаптивным интерфейсом.
3. Реализовать backend API для авторизации, счетов, карт и операций.
4. Спроектировать базу данных.
5. Реализовать личный кабинет пользователя.
6. Добавить историю транзакций и аналитику расходов.
7. Реализовать админ-панель для управления пользователями и операциями.
8. Добавить базовые элементы безопасности: JWT, хеширование паролей, роли, валидацию данных.

## Актуальность

Современные банки всё чаще переходят в цифровой формат. Пользователям важно иметь быстрый доступ к своим деньгам, картам, переводам и статистике расходов. Учебная модель G.M.W Bank помогает изучить принципы создания сложных веб-приложений, где есть авторизация, база данных, бизнес-логика, UI/UX и защита данных.

## Роли

- Клиент
- Сотрудник поддержки
- Администратор

## Уникальные функции

- G.M.W Score — внутренний рейтинг пользователя.
- Виртуальный кешбэк.
- Финансовые цели.
- Категоризация расходов.
- Управление лимитами карты.
